# 西安三日游 · 行程规划网页

一个零依赖、零构建的静态单页站点，把西安三天两晚的**景点、美食、路线、酒店、预算、贴士**排在一页里讲清楚。

## 怎么打开

直接双击 `index.html` 就能在浏览器里看，不需要装任何东西、不联网也能正常显示（所有配图都是手写的 SVG，没有外链图片）。

如果想用本地服务器打开（比如想在手机上访问）：

```bash
python -m http.server 8000
# 然后浏览器访问 http://127.0.0.1:8000/index.html
```

## 文件结构

```
index.html      页面骨架，只放容器和少量静态标记
styles.css      全部样式：配色、排版、响应式、打印样式
data.js         所有内容数据（景点/美食/路线/酒店/贴士）——改文案只动这个文件
app.js          渲染逻辑 + 交互 + 景点插画
```

## 页面包含什么

| 区块 | 内容 |
| --- | --- |
| 行程总览 | 三天节奏、强度、方向，点卡片直接跳到对应路线 |
| 三日路线 | 每天 6–7 个节点的**时间轴**，含时长、交通、一句话建议和 Plan B |
| 必去景点 | 12 个景点，可按「历史古迹 / 博物馆 / 自然风光 / 夜景打卡」等 8 个类别筛选，每张卡有门票、建议时长、预约方式、实话建议 |
| 特色美食 | 15 样小吃，按主食 / 小吃 / 饮品筛选，标了人均和本地人常去的店 |
| 住宿选址 | 3 个片区（钟楼·南门 / 大雁塔·曲江 / 北客站）各自的优缺点 + 三档价位酒店 |
| 预算估算 | 选人数和档次，实时算出人均和总花费，并列出住宿/门票/餐饮/交通的明细 |
| 实用贴士 | 交通、预约、季节穿着、避坑提醒，外加一份可勾选的出发清单 |

## 交互功能

- 顶栏滚动进度条 + 当前章节自动高亮
- 三日路线 Tab 切换，行程总览卡片一点直达
- 景点 / 美食类别筛选
- 住宿片区切换
- 预算计算器（人数 × 档次 联动）
- 出发清单可勾选
- 响应式（手机端折叠菜单）+ 打印样式（可直接「打印 / PDF」存成手册）

## 怎么改内容

想加一个景点，在 `data.js` 的 `attractions` 数组里追加一项就行：

```js
{
  id: "unique-id",                 // 唯一标识，同时用作 SVG 渐变的 id
  name: "景点名", area: "所在区", art: "citywall",   // art 决定配图
  cats: ["历史古迹", "夜景打卡"],   // 用于筛选
  ticket: "54 元", duration: "2 小时", rating: "★★★★★",
  book: "预约方式",
  desc: "一句话介绍",
  tip: "实话建议"
}
```

`art` 可选值：`terracotta`（兵马俑）、`citywall`（城墙）、`pagoda`（大雁塔）、`belltower`（钟鼓楼）、`museum`（博物馆）、`nightcity`（夜景）、`palace`（宫苑）、`mountain`（山岳）、`street`（街市）、`stele`（碑林）、`lake`（园林）、`minggong`（宫殿遗址）。

美食、行程、酒店、贴士同理，都在 `data.js` 里，格式照抄现有条目即可。

## 两点说明

- 门票价格、开放时间、预约规则会随季节调整，页面里的数据是常见的旺季口径，出行前请以景区官方公众号为准。
- 单位是人民币。「预算估算」不含往返西安的大交通（机票 / 高铁）。
